# String Tag

JavaScript utilities for getting and checking the string tag of a value.

## Installation

```
npm install @yurkimus/string-tag
```

## Exports

- `toStringTag(value)` — returns the string tag of a value, e.g. `'Array'`.
- `isStringTag(stringTag, value)` — checks whether the string tag of a value equals `stringTag`.
